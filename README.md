# Automated data evaluation, record and transfer system.

## Purpose

Automate the process of collecting, collating, evaluate and transferring data.

## Built With

- n8n.com

- Google Forms

- Google Sheets

- Gmail
- JSON code

## Workflow

Google Form (data input)

↓

Google Sheets (upload)

↓

JSON Code (data evaluation)

↓

Google Sheets (upload)

↓

Email (send and retrieve)
↓
Google Sheets (data append)

↓

Gmail (approval request)

↓
Gmail (record transfer)


## Features

- Captures data,

- Record captured values into a spreadsheet,

- Execute calculation of data in the spreadsheet,

- Upload new values into another spreadsheet,

- Send an email to request the final value to complete the table,

- Append into the spreadsheet,

- Send another email for verification and approval,

- Transfer of record to delegated personnel via email.
